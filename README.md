# EEcoE App

Frontend institucional do Espaço Ecológico Educativo — IFRJ Campus Pinheiral.

## Stack
- React
- TypeScript
- Vite
- Bootstrap 5
- Bootstrap Icons
- React Router

## Executar
```bash
npm install
npm run dev
```

O projeto é somente frontend neste estágio. Os dados podem ser simulados posteriormente com Mock Data/LocalStorage e, em uma etapa futura, substituídos por uma API.
